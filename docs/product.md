# Product

## Concept

高価で数年間使う愛用品について、**どれくらい使ったか・あとどれくらい使いたいか・どこまでコストを下げられたか**を可視化し、納得できるタイミングで次の買い替えを判断できるようにする。

このアプリは買い替えを促すことを目的としない。

「まだ使う」「そろそろ考える」「十分使った」という状態を分かりやすく示し、**十分使ったという納得感を持って次へ進めること**を重視する。

また、目標期間を超えて使い続けることもポジティブに扱い、長く使う選択肢も支援する。

## Target

iPhone、Mac、Apple Watchなどのガジェットを代表的な利用例としつつ、ガジェット専用には限定しない。

バッグ、財布、カメラ、腕時計など、次の特徴を持つ愛用品を主な対象とする。

- ある程度高価である
- 数年間使う
- 定期的に買い替える可能性がある
- 買い替え時に「もう十分使ったか」を考える

家計簿、資産管理、製品寿命管理を主目的とはしない。

## Core Experience

基本的な利用の流れは次のとおり。

1. 現在使っている愛用品を登録する
2. 使用期間・使用目標・コストを確認する
3. 使用目標の90%に達したら、買い替えを考え始める
4. 100%に達したら、十分使ったことを「目標達成」として確認する
5. 必要であればそのまま使い続ける
6. 実際に使い終えたときに「買い替え完了」にする
7. 過去に使ったものとして履歴に残す

## Item Data

MVPでは、愛用品ごとに次の情報を登録する。

- 名前
- カテゴリ
- 購入日
- 購入価格
- どれくらい使いたいかという目標期間

カテゴリは主に分類と表示上のアイコン用途に使用する。

カテゴリによって買い替え時期や目標期間を自動判定しない。

## Replacement Progress

使用目標に対する進捗率によって、現在の状態を次のように扱う。

### 0〜89%

**まだ使いたい**

使用目標まで十分な期間が残っている状態。

### 90〜99%

**買い替えを考え始める**

買い替えを要求するのではなく、次の選択肢を考え始めてもよい時期として扱う。

### 100%以上

**目標達成**

設定した使用目標を達成した状態。

期限切れや使いすぎとして扱わない。100%を超えて使い続けることもポジティブに表示する。

100%への到達は「買い替え完了」を意味しない。実際に使用を終了するまで、そのアイテムは使用中のままとする。

## Home

Homeは単なる持ち物一覧ではなく、**現在使っているものの中から、次に何を見直すべきか把握するためのダッシュボード**とする。

### 次に見直すもの

Home上部に、現在もっとも見直し優先度が高いアイテムを1件表示する。

優先順位は次のとおり。

1. 100%以上：目標達成
2. 90〜99%：買い替えを考え始める
3. 0〜89%：まだ使いたい

同じ状態の中では、使用目標に対する進捗率が高いものを優先する。

### アイテム一覧

各アイテムでは、主に次の情報を確認できるようにする。

- 名前
- 状態
- 進捗率
- 残り期間または目標超過期間
- 現在までの使用期間
- 現在の1日あたりコスト

購入価格や購入日の詳細確認はItem Detailを中心とする。

Home下部から「これまで使ったもの」へ遷移できる。

## Item Detail

Item Detailは、**その愛用品をまだ使うか、買い替えを考えるか判断するための材料を見る場所**とする。

主に次の情報を表示する。

- 名前
- カテゴリ
- 購入日
- 購入価格
- 現在までの使用期間
- 使用目標
- 進捗率
- 残り期間または目標超過期間
- 現在の1日あたりコスト
- 使用目標まで使った場合の1日あたりコスト
- さらに1年使った場合の1日あたりコスト

「さらに1年使った場合」のコストも示すことで、買い替える判断だけではなく、使い続ける選択肢も支援する。

Item Detailから次の操作を行える。

- 編集
- 買い替え完了
- 削除

## Replacement Completed

実際にその愛用品の使用を終了したとき、ユーザーが明示的に「買い替え完了」を実行する。

買い替え完了時には使用終了日を記録する。

完了後も記録を削除せず、これまで使ったものとしてHistoryに残す。

買い替え完了時には、最終的な使用期間と1日あたりコストを確認できるようにする。

完了後、新しい愛用品の登録へ進める導線を提供する。

MVPでは、古いアイテムと新しく登録したアイテムをデータ上で直接関連付ける必要はない。

## Delete

削除と買い替え完了は別の操作として扱う。

- **買い替え完了**：実際に使い終えた記録を履歴として残す
- **削除**：登録ミスなど、記録そのものを完全に消す

削除時には確認を行う。

Historyにあるアイテムも削除可能とする。

## History

Historyでは、買い替え完了した愛用品を振り返ることができる。

Homeの主要機能ではないため独立したTabにはせず、Home下部の「これまで使ったもの」から遷移する。

一覧では主に次の情報を表示する。

- 名前
- 最終使用期間
- 最終的な1日あたりコスト
- 使用開始から終了までの期間

Historyから過去のアイテム詳細を確認できる。

MVPでは買い替え完了の取り消しは提供しない。

## Empty State

アイテムが1件もない場合、大規模なオンボーディングは行わない。

このアプリの価値を簡潔に説明し、最初の愛用品登録へ誘導する。

最初の1件を登録することで、使用期間・残り期間・1日あたりコストがすぐ確認でき、このアプリの価値を理解できる体験を重視する。

## MVP Screens

MVPの主要画面は次のとおり。

- Home
- Add / Edit Item
- Item Detail
- History
- History Detail

加えて、買い替え完了や削除確認などに必要な補助UIを使用する。

## Platform and Technical Constraints

MVPでは次を前提とする。

- iPhone向けネイティブアプリ
- iOS 18以上
- SwiftUI
- SwiftData
- Apple標準のUI・操作体系を中心にする
- ローカル保存のみ
- iPadはサポート対象外
- macOSアプリは対象外
- watchOSアプリは対象外

MacやApple Watchは管理対象として登録できるが、対応プラットフォームではない。

## Out of Scope for MVP

次の機能はMVPには含めない。

- OpenAI APIによる買い替えアドバイス
- AIによる買い替え時期の自動判定
- 通知
- アカウント
- クラウド同期
- 製品データベース
- 製品画像の自動取得
- 買い替え候補商品の提案
- 買い替え予算・積立管理
- 古いアイテムと新しいアイテムの買い替え関係の明示的な紐付け
- iPad対応
- macOS対応
- watchOS対応

これらは、MVPで買い替え判断支援という中心価値が成立することを確認した後に必要性を判断する。
